## 🚀 Key Features

### Comprehensive Vulnerability Detection
ZeroTrace performs detailed scans to uncover a variety of potential security weaknesses:

- 🔍 Cross-Site Scripting (XSS)
- 🛡️ Clickjacking
- 🔗 HTTP Parameter Pollution (HPP)
- 🍪 Cookie Vulnerabilities
- 💉 SQL Error Exposure
- 🔄 Cross-Site Request Forgery (CSRF)
- ⏎ Carriage Return Line Feed (CRLF) Injections
- 📂 Local File Inclusion (LFI)
- 📁 Directory Listing
- 🚫 Unauthorized Access
- 📊 Insightful Reporting

### Detailed Analysis & Reporting
- 📝 Comprehensive vulnerability summaries

## 🛠️ Technical Stack

ZeroTrace leverages several powerful Python libraries to deliver its functionality:

- `requests`: Seamless HTTP interactions
- `bs4 (BeautifulSoup)`: HTML and XML parsing
- `lxml`: Efficient XML and HTML processing
- `tldextract`: Accurate top-level domain identification
- `execjs`: JavaScript execution capabilities
- `jinja2`: Flexible report templating
- `CSS3`: Modern styling and responsive design

## 🚀 Getting Started

### Prerequisites
- Python 3.7 or higher
- pip (Python package manager)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/garv04/ZeroTrace.git
   cd ZeroTrace
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### Usage

1. Launch the tool:
   ```bash
   python main.py
   ```

2. Follow the interactive prompts to:
   - Enter target URL
   - Choose scan mode
   - Configure scan options
   - Review generated reports

### Report Generation

Reports are automatically generated in HTML format with modern styling. The reports include:
- Executive summary
- Vulnerability statistics
- Detailed findings
- Technical details
- Remediation recommendations
- Scanned pages list
